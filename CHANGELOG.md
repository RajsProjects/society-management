# Changelog

All notable changes to this project will be documented here.

## [1.0.0] - 2026-05-07

### Added
- JWT-based authentication with role-based access control
- User management with PENDING → ACTIVE approval workflow
- Issue reporting and community voting system
- Maintenance billing with UPI payment simulation
- Announcements and alerts module
- Global exception handling and structured logging
- Swagger UI API documentation
- Docker and Kubernetes support
- Prometheus and Grafana observability
- GitHub Actions CI/CD pipeline
- Unit tests with JUnit 5 and Mockito
